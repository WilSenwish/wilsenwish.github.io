**独立负责人**

**技术栈**：Spring Cloud Gateway、Nacos、OpenFeign、TransmittableThreadLocal、JWT、RocketMQ

**项目描述**：独立负责两条基础设施线：微服务底座支撑教师评价系统单体 → 微服务（4 个服务 / 3 台机器）；公共组件以 Starter 接入 10+ 个项目。

**核心工作**

2. **公共组件**：可监控线程池统一隔离规范并暴露队列水位、活跃线程、任务耗时；通用工具库与 Web-Starter 收敛日期 / 文件 / Excel / 加解密 / 鉴权等能力，新项目引入即用。

**结果**：微服务改造稳定运行，具备服务级独立部署、故障隔离与水平扩展；公共组件被 10+ 个项目复用，消除重复实现。

### 项目 3｜自研 APM 可观测性平台 ｜2019.06 - 至今
**独立全栈开发**

**技术栈**：Java、SPI、RocketMQ、Protostuff、MongoDB、Vue

**项目描述**：因客户机房网络差异，调研 SkyWalking / Prometheus / OpenTelemetry 后自研轻量 APM（微内核 + SPI），覆盖 Trace、接口性能、JVM / 线程池、异常与业务事件。

**核心工作**

1. **架构与链路**：Agent SDK 支持零代码与显式埋点双模式；TransmittableThreadLocal 透传 Trace 上下文，解决跨服务层级嵌套；多级采样责任链按接口 / Debug / 预热 / 异常 / 慢事件 / 兜底比例采样。
2. **上报与稳定性**：推拉双模适配不开放外网的客户内网；Protostuff 降带宽；RocketMQ ACL 改造实现 Group / Topic 级隔离；监控自身复用可监控线程池，不拖慢业务。

**结果**：接入 17 个业务系统（24 个服务）/ 47 台机器，迭代 30+ 次；分钟级统计 P99 < 1s，告警推送 < 3min。
