### 项目 3｜自研 APM 可观测性平台｜2019.06 - 至今
**独立全栈开发**

**技术栈**：Java、SPI、Spring Boot、RocketMQ、MongoDB、Redis、Vue

**项目描述**：因客户机房网络差异，调研 SkyWalking / Prometheus / OpenTelemetry 后自研轻量 APM（微内核 + SPI），采集 Trace、日志 / 事件、接口性能、JVM / OS、线程池、异常与业务事件。

**核心工作**

1. **架构与链路**：Agent SDK 零代码与显式埋点双模式；TransmittableThreadLocal 透传 Trace 上下文，解决跨服务层级嵌套；多级采样责任链按接口 / Debug / 预热 / 异常 / 慢事件 / 兜底比例采样。
2. **上报与稳定性**：推拉双模适配不开放外网的客户内网；Protostuff 降带宽；RocketMQ ACL 改造用于集群整体安全防护；监控自身复用可监控线程池，不拖慢业务。

**结果**：覆盖 17 个业务系统（24 个服务）/ 47 台机器，迭代 30+ 次；告警推送 < 3min。
